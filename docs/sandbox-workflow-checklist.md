# Sandbox Workflow Checklist

A safe OpenSense attempt should keep generated changes inside the sandbox until reviewed.

1. Build the issue pack.
2. Review the generated plan.
3. Create a sandbox worktree.
4. Apply the agent attempt only after explicit approval.
5. Run tests and capture raw evidence.
6. Draft the PR text locally.

The workflow should produce evidence first and leave GitHub write actions to a separate human decision.
