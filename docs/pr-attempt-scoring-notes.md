# PR Attempt Scoring Notes

A PR attempt score should reflect both usefulness and execution risk.

Signals to consider:

- Testability of the issue.
- Size of the affected code area.
- Clarity of maintainer expectations.
- Risk of touching security, payment, legal, or licensing behavior.
- Whether an existing PR already covers the same request.

The score is a decision aid, not an instruction to auto-commit or auto-open a PR.
